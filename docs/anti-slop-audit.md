Дата: 17 ноября 2026. Метод: для каждого визуального элемента — пять вопросов
(что обозначает / какую задачу решает / есть ли достовернее / нужно ли /
можно ли заменить реальным содержимым). Вердикты: KEEP / REDESIGN / REMOVE /
FIX. Ссылки на проблемы — из `docs/visual-audit.md` (VA-xx).

Общий вывод: рабочая платформа уже дисциплинирована (нет glow/градиентов/
glass на поверхностях, KPI без иконок, один shadow-токен, честные DEMO-маркеры).
Основной «slop» сосредоточен в **демонстрационном слое showcase** и в
**синтетических кадрах**, плюс гигиена ассетов. Это исправляется заменой
декоративных рисунков реальными материалами продукта, а не сменой стиля.

## 5. Итоговые действия

- REMOVE: Sparkline, 6 мертвых иконок, `.dots`, strokeDasharray-артефакт.
- REDESIGN: Pipeline-визуалы (8 стадий → реальные материалы), Scenario-визуалы
  (HTML из данных), demo-кадры (дневная уличная сцена).
- FIX: fallback-числа, ColumnChart (оси/empty), segmented-контраст,
  keyboard-пробелы, toast dismiss, confirm отмены job, size-check upload,
  ErrorState jobs-панели, LQIP, шрифтовые несоответствия, токены в SVG.
- KEEP: вся остальная визуальная система — она уже соответствует
  профессиональным принципам (см. visual-research.md) и не является slop.

Ни один элемент не удалён «автоматически»: каждый вердикт обоснован
пятью вопросами выше. Реальные данные нигде не заменяются mock-значениями;
demo остаётся явно маркированным.
