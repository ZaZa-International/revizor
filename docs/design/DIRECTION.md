# REVIZOR — Visual Direction

Дата: 16 ноября 2026. Результат этапа reconnaissance (frontend + backend contract + KDF).

## Исходное состояние

Frontend в репозитории **отсутствовал**: проект содержал только backend (FastAPI,
47 endpoints, OpenAPI 3.1, seed-данные). Frontend создаётся с нуля в `frontend/`.
Источник истины по данным — `contracts/openapi/openapi.json` и
`docs/integrations/frontend-contract.md`. Контракты backend не меняются.

## Изученный референс: KDF (kaspian-digital-forum)

Изучены `docs/design/DIRECTION.md`, `MASTER.md`, `QA.md`, `PRODUCT_WORKSPACE.md`,
`PLATFORM_V2_QA.md` и реализация (`freight-hero.js`, `command.js/css`,
`workspace.html/js/css`, `caspian-scene.js`, `flat-map.js`, vendor-ассеты).

Конкретные решения, адаптируемые для Revizor (без копирования контента/тематики):

1. **Две самостоятельные части**: презентация `/` и рабочая платформа `/app`
   с собственными URL, общей навигацией и прямым входом без прохождения сцены.
2. **Scroll-scrub без scroll-jacking**: нативная прокрутка; прогресс сцены
   вычисляется из `getBoundingClientRect`, сглаживание lerp, обратимость,
   rAF только при изменении, остановка вне видимости и при `document.hidden`.
3. **Единая система движения**: micro 180 мс; вход 550 мс `power3.out` 18–22 px;
   смена карточки 240 мс opacity+transform. Reduced motion — статичный рассказ,
   все функции доступны.
4. **Токены**: отдельная граница контролов (`--control-border`) от декоративных
   линий; радиусы 3–7 px; шаг 4 px; тени только временным слоям; focus-visible
   outline; skip-link; нативные диалоги с Escape.
5. **Честность данных**: demo-данные маркированы; отсутствие данных не
   подменяется нулём; единицы измерения меньше значений; источник и основания
   показателей видны в интерфейсе.
6. **Fallback**: интерактивная SVG-карта при отказе WebGL/сети; постер при
   отказе медиа; локальные шрифты и геометрия, без платных ключей.
7. **QA-дисциплина**: Playwright-сценарии с evidence, два независимых визуальных
   цикла, проверка ширин 360–1920, расчёт контрастов токенов.

Отличия Revizor: собственная палитра (graphite/mint/amber/red), собственная
драматургия «город → сеть → наблюдение → решение», предметная графика
телеком-инфраструктуры, React+TS вместо vanilla (обоснование ниже).

## Продуктовая история

**Город → Сеть → Наблюдение → Обнаружение → Оценка → Решение → Контроль состояния.**

Метафора: **THE CITY IS A NETWORK.** Три мира в одной визуальной системе:
urban photography (реальные фото Москвы и телеком-объектов), geospatial
intelligence (сеть, координаты, слои), infrastructure operations (диспетчерская,
статусы, история). Никакой «нейро-эстетики»: предметность важнее абстракции.

## Стек (обоснование)

- **React 18 + TypeScript + Vite** — frontend отсутствует, терять нечего;
  repo уже готовит typed-контракт (`openapi-typescript` schema.d.ts +
  recommended `openapi-fetch` в docs/integrations/README.md). 10 рабочих
  разделов, мутации, оптимистичные блокировки, polling — компонентная модель
  и route-level code splitting снижают риск ошибок против vanilla.
- **TanStack Query v5** — server-state: кэш, polling jobs (1.5 с), invalidation
  после reviews/PATCH, retry-политика по кодам ошибок контракта.
- **react-router v6** — `/` showcase, `/app/*` nested routes, прямые URL и reload.
- **MapLibre GL JS** — backend отдаёт GeoJSON «для MapLibre» (контракт §5).
  Без API-ключей. Тёмный raster-basemap (Esri World Dark Gray, attribution) + локальный
  интерактивный SVG-fallback (офлайн/отказ WebGL) с теми же данными.
- **GSAP + ScrollTrigger** (npm, free license) — scrub-сцены showcase.
- **SVG-графики собственной реализации** — распределения, sparklines, timeline,
  coverage-grid. Без chart-библиотек: полный контроль стиля, малый bundle.
- **Plain CSS + design tokens** — без UI-китов и Tailwind; уникальная идентичность.
- **Vitest + Playwright** — unit и E2E против demo-режима и живого API.

## Палитра и типографика

Направление токенов (контраст проверяется расчётом, см. docs/design-system.md):
deep graphite `#091318` / рабочая поверхность `#102129` / вторичная `#1C3038`;
светлая редакционная `#F2F3EF`; текст `#E9EEE9` / `#A0B3B5`; сетевой акцент
mint `#75D7CC`; warning amber `#F0A45C`; critical red `#E66C61`.
Статус = цвет + текст + иконка. Один акцент для действий, семантические цвета
только для состояний.

Шрифты (локально, OFL, кириллица): **Oswald** — display (узкий гротеск,
uppercase, характерные заголовки), **IBM Plex Sans** — интерфейс и текст,
**JetBrains Mono** — координаты, ID, табличные данные.

## Драматургия showcase (`/`)

1. **Opening** — ночная аэрофотография Москвы (CC BY 4.0, локально),
   крупная типографика «ГОРОДСКАЯ СЕТЬ. ПОД НАБЛЮДЕНИЕМ.», координатная строка,
   прорисовка сети поверх фото. CTA: «Открыть платформу», «Как это работает».
2. **The Invisible Network** — scrub-переход фото → техническая схема сети
   (объекты, линии, узлы, зоны), счётчики из реального API либо явно demo.
3. **How It Works** — вертикальный pipeline из 8 стадий с последовательным
   раскрытием и предметными SVG-иллюстрациями (не 8 одинаковых карточек).
4. **The Digital Infrastructure** — интерактивная карта/схема сети: слои,
   выбор объекта → паспорт. Demo-сценарий маркирован; при живой сессии —
   реальные данные API.
5. **Intelligence in Action** — пошаговый сценарий: кадр → detection bbox →
   дедупликация → наблюдение → review → история состояния.
6. **Command Center** — честная демонстрация реализованных экранов платформы.
7. **Final transition** — «УПРАВЛЯЙТЕ СОСТОЯНИЕМ ИНФРАСТРУКТУРЫ» → `/app`.

## Command Center (`/app`)

Тёмная рабочая среда. Desktop: фиксированный левый rail + верхняя контекстная
панель + рабочая область + правые контекстные панели (карта, review).
Mobile: компактная навигация, приоритет основного действия, без горизонтального
скролла. Разделы: Overview, Map, Assets, Observations, Defects, Reviews, Jobs,
Routes, Analytics, Exports — все поддержаны backend.

Данные: только реальный API в live-режиме. Отдельный **явный demo-режим**
(детерминированный синтетический датасет, маркировка DEMO на каждом экране,
не смешивается с live). При недоступном backend — предложение demo, не тихая
подмена. Privacy: изображения не выдаются за анонимизированные (backend
NoopPrivacyFilter → NOT_APPLIED, показываем как есть).

## Ограничения проверки

Модель-исполнитель не поддерживает просмотр изображений: визуальный QA
выполняется программно (геометрия DOM, overflow, контраст, видимость, состояния)
+ скриншоты-артефакты для человеческого просмотра. Это фиксируется в финальном
отчёте; скриншоты сохраняются в `frontend/artifacts/qa/`.
