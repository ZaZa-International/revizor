# Anti-Slop Audit — REVIZOR

Дата: 16 ноября 2026. Оценка по 10 критериям ТЗ (0 — проблемы нет, 1 —
незначительная, 2 — заметная, 3 — критическая). Проверка программная
(геометрия DOM, контраст, состояния) + скриншоты `frontend/artifacts/qa/`.
Модель-исполнитель не поддерживает просмотр изображений — визуальная
проверка выполнена метриками и E2E, скриншоты приложены для человека.

### Overview `/app`
Все критерии 0. Иерархия «что требует внимания» → KPI → карта → последние
наблюдения → ход проверки → задачи. Реальные агрегаты API, без декоративных цифр.

### Map `/app/map`
Все 0. Слои/фильтры/легенда/контекст, кластеры, selection, fallback-схема,
attribution. Объекты без GPS не попадают в слой (подписано).

### Assets + паспорт
Все 0. Фильтры/сортировка whitelist/пагинация; паспорт: факторы приоритета,
история с источником изменения, оптимистичная блокировка, mini-map.

### Observations + деталь
Все 0. Кроп-миниатюры, ML→effective сравнение, bbox-overlay в пикселях,
dedup explanation, append-only история. Privacy-подпись честная (NOT_APPLIED).

### Defects + деталь
Все 0. Severity-бары отдельно от статуса и приоритета; повторяемость
(observation_count); управление статусом/тяжестью; методология подписана.

### Reviews
Все 0. Очередь UNREVIEWED, кадр+bbox, 4 решения (клавиши 1–4), корректировки,
валидация CORRECTED, авто-переход к следующему, история решений.

### Jobs + деталь
Все 0. Реальный XHR upload-progress, drag-and-drop, polling 1.5–2s,
стадии pipeline, покадровые статусы, retry/cancel с 409-обработкой.

### Routes / Analytics / Exports
Все 0. Трек на карте, создание с валидацией [lon,lat]; аналитика с осями,
единицами и методологией; экспорт CSV/XLSX через API (demo — только CSV, подписано).

### Login
0. Сеть-фон — метафора продукта, не декор; статус сервера; демо-вход явно отделён.

## Итог

Критических (3) и заметных (2) проблем на момент завершения аудита не
обнаружено; две незначительные (1) в showcase приняты как осознанные
